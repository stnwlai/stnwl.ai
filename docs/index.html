Innovation Stack

Four evidence contracts working together

The reference follows a narrow path from strict source records to reproducible outputs, cited retrieval results, and a reviewed publication tree.

Each contract is readable, runnable, and tested without a service, database, model key, or third-party Python package.
🔐

Content-Addressed Evidence

Canonical JSON, per-artifact SHA-256 digests, and a deterministic Merkle root bind the catalog and retrieval index to the same corpus.

$ PYTHONPATH=src python3 -m stonewall build
"artifact_count": 78
"chunk_count": 554
🔗

Line-Verifiable Citations

Every hit carries its source path, original line range, artifact digest, and span digest. Verification reopens the artifact and checks both layers.

D0001:7-7@af7d25ba403d
artifact SHA-256 + span SHA-256
🔎

Explainable Retrieval

Dependency-free BM25 ranking reports its relevance, heading, and exact-phrase components rather than returning an opaque score.

bm25          4.36619916
heading boost  0.95257955
exact phrase   0.0
🛡️

Publication Boundary

An exact-tree manifest, coded-metadata allowlist, path rules, and non-echoing content checks fail closed before a candidate tree can publish.

$ PYTHONPATH=src python3 \
  scripts/check_public_boundary.py
Public boundary verified

CLI Demo

Commands that prove the contracts

The examples below compile the checked-in corpus, retrieve cited spans, and verify reproducibility.

The package uses only the Python standard library, so the evidence path is runnable without service credentials or dependency installation.
build
$ PYTHONPATH=src python3 -m stonewall build
builder        : stonewall-evidence
artifact_count : 78
chunk_count    : 554
query
$ PYTHONPATH=src python3 -m stonewall \
  query "deposition scheduling" \
  --limit 3 --verify-citations
count : 3
top   : D0001:7-7@af7d25ba403d
boundary
$ PYTHONPATH=src python3 \
  scripts/check_public_boundary.py
Public boundary check passed.
verify
$ PYTHONPATH=src python3 -m stonewall \
  verify --output build/reference

artifact_count : 78
chunk_count    : 554

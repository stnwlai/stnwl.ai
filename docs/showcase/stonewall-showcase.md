# Stonewall Showcase

Stonewall is a citation-first legal document intelligence platform. This page is
the showcase narrative entry point.

Start with [Quarterback](../../archive/stonewall-showcase/quarterback/README.md),
then read the [evidence-fabric design note](../evidence-fabric.md) or run the
implementation from the repository root.

## What this showcase demonstrates

- deterministic compilation and content-addressed evidence bundles;
- source-line citations with artifact and span verification;
- explainable dependency-free retrieval;
- an exact-tree publication gate.

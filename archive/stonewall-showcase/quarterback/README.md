# Quarterback Overview

Stonewall is citation-first legal document intelligence. The engineering
reference demonstrates a compact evidence path from strict coded records to
reproducible bundles, transparent retrieval scores, and line-verifiable
citations.

## Reference stack

### Content-addressed evidence

Canonical JSON, artifact digests, and a deterministic Merkle root bind the
catalog and retrieval index to the same corpus.

### Line-verifiable citations

Every hit carries a repository-relative path, original line range, artifact
digest, and selected-span digest.

### Explainable retrieval

The dependency-free retrieval layer reports BM25, heading, and exact-phrase
signals separately.

### Publication boundary

Git-derived candidate enumeration, metadata contracts, non-echoing content
checks, and an exact-tree manifest form a blocking release gate.
